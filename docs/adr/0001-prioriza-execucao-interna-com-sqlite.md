# Prioriza execução interna com SQLite

O Hiperion Protocolos é uma aplicação operacional interna e adota Node.js com SQLite como forma principal de execução, reduzindo dependências externas e mantendo os dados na infraestrutura da organização. Vercel e Turso permanecem como mecanismos de portabilidade para homologação, demonstração ou acesso web autorizado, sem transformar a hospedagem em nuvem no propósito central do produto.
